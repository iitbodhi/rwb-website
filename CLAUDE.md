**What RWB is:** the TVS Ronin community app for Ronin Warriors of Bengal.
- Website: roninwb.in, served by GitHub Pages from this repo (iitbodhi/rwb-website). Pushing to `main` makes it live in about 2–10 minutes.
- The app: `app/` folder. The Android app (package `in.roninwb.twa`, built with Capacitor) loads its screens from roninwb.in/app. So **web changes reach every installed copy without a new build**.
- A new Android build is needed only for native changes: icon, the Track background service, notifications, Google sign-in sheet, permissions. Those live in `android-app/`.

- Backend: Supabase (project region ap-northeast-2, Seoul), free plan. Watch the egress usage.
- Member sheet: the RWB_Contact Google Sheet, synced every 12 hours by `tools/form-sync.gs` (Apps Script). Since Nov 2026 the old Google join form (retired by file 75) is **not linked** to the sheet (every re-link made a new "Form responses N" tab and entries went missing): a trigger on the form (`onJoinForm`) sends each entry to the app and writes it into the one **Members** tab (formerly "Form responses 3"), found by its ID (script property `membersTabId`). `keepFormUnlinked_` (in setup and every check) unlinks the form if someone links it again and hides stray response tabs. `addMissedEntries` picks up entries the tab missed. Egress: the 12-hour check (`sheet_export_all`) is ~1.2 MB since file 67 (long question titles cut to 120 chars; was 8.75 MB). Don't make it run more often. File 79 (Nov 21 2026, after an 8.8 GB egress month put the org in a grace period; no new grace period if it happens again): `api.admin.members()` keeps the list on the admin's phone (`savedGet/savedSet` in offline.js, key `keep|admin-members|<uid>`) and calls `admin_members_since(p_since)` for only rows changed since (members.updated_at via `zz_members_touch`, bike changes in `private.member_touch`, removals in `private.member_gone`); full download weekly; `membersAll` is the old full fetch.
